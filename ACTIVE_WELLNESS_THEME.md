# Active Wellness Brand Theme

## Color Palette

Based on wellness/spa industry standards and professional health brand aesthetics:

### Primary Colors
```
Primary (Teal/Wellness Green): #00897B
- Use for: Primary actions, highlights, success states
- WCAG AA Compliant on white backgrounds

Primary Dark: #00695C
- Use for: Hover states, emphasis
- Enhanced contrast for accessibility

Primary Light: #4DB6AC
- Use for: Subtle backgrounds, hover effects
```

### Secondary Colors
```
Secondary (Calm Blue): #0288D1
- Use for: Information, links, secondary actions
- Professional healthcare aesthetic

Secondary Dark: #01579B
- Use for: Darker variants, hover states

Secondary Light: #4FC3F7
- Use for: Light backgrounds, accents
```

### Neutral Colors
```
Background: #FAFAFA (Off-white)
- Main application background
- Soft, easy on eyes

Surface: #FFFFFF (White)
- Cards, panels, elevated surfaces

Text Primary: #1A1A1A (Near-black)
- Main content text
- High contrast for readability

Text Secondary: #616161 (Medium gray)
- Supporting text, labels
- Subtle hierarchy

Border: #E0E0E0 (Light gray)
- Dividers, borders, outlines
```

### Accent Colors
```
Success (Bookings): #43A047 (Wellness green)
- Positive outcomes, completed actions
- Growth, health associations

Warning (Pending): #FB8C00 (Warm orange)
- Pending states, attention needed
- Energetic but not alarming

Error: #E53935 (Coral red)
- Errors, failed states
- Softer than harsh red

Info: #039BE5 (Sky blue)
- Informational messages
- Calming, trustworthy
```

### Dark Mode Adjustments
```
Background Dark: #0A0A0A (Almost black)
Surface Dark: #1E1E1E (Dark gray)
Text Primary Dark: #FAFAFA (Off-white)
Text Secondary Dark: #B0B0B0 (Light gray)
Border Dark: #333333 (Dark gray)

Primary in Dark Mode: #4DB6AC (Lighter teal for contrast)
Secondary in Dark Mode: #4FC3F7 (Lighter blue)
```

## Typography

### Font Families
```
Headings: 'Inter', -apple-system, sans-serif
- Clean, modern, professional
- Excellent readability

Body: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
- System fonts for performance
- Native feel on all platforms
```

### Font Sizes
```
Display: 3rem (48px) - Hero headings
H1: 2.5rem (40px) - Page titles
H2: 2rem (32px) - Section headings
H3: 1.5rem (24px) - Subsections
H4: 1.25rem (20px) - Card titles
Body: 1rem (16px) - Main content
Small: 0.875rem (14px) - Captions, labels
Tiny: 0.75rem (12px) - Metadata
```

### Font Weights
```
Light: 300 - Rarely used
Regular: 400 - Body text
Medium: 500 - Emphasis
Semibold: 600 - Subheadings
Bold: 700 - Headings
```

## Border Radius

```
sm: 4px - Subtle rounding
md: 8px - Standard cards
lg: 12px - Prominent cards
xl: 16px - Large panels
full: 9999px - Pills, badges
```

## Shadows

```
sm: 0 1px 2px rgba(0, 0, 0, 0.05)
- Subtle elevation

md: 0 4px 6px rgba(0, 0, 0, 0.07)
- Standard cards

lg: 0 10px 15px rgba(0, 0, 0, 0.1)
- Elevated panels

xl: 0 20px 25px rgba(0, 0, 0, 0.15)
- Modals, overlays
```

## Design Principles

1. **Clean & Spacious**: Generous padding, not cramped
2. **Calming**: Soft colors, smooth transitions
3. **Professional**: Medical/wellness credibility
4. **Accessible**: WCAG AA compliant minimum
5. **Modern**: Contemporary design patterns
6. **Trustworthy**: Consistent, predictable UI

## Animation Timings

```
Fast: 150ms - Micro-interactions
Normal: 200ms - Hover states
Medium: 300ms - Transitions
Slow: 500ms - Page transitions
```

## Application to Dashboard

### Metric Cards
- Background: White (Surface)
- Border: #E0E0E0
- Icon Background: Primary color at 10% opacity
- Icon: Primary color
- Value: Text Primary (#1A1A1A)
- Label: Text Secondary (#616161)
- Trend positive: Success (#43A047)
- Trend negative: Error (#E53935)

### Charts
- Call volume: Primary (#00897B) and Secondary (#0288D1)
- Outcomes pie: Success (#43A047), Warning (#FB8C00), Error (#E53935), Info (#039BE5), Primary (#00897B)
- Grid lines: Border (#E0E0E0)
- Labels: Text Secondary (#616161)

### Buttons
- Primary: Background #00897B, Text #FFFFFF
- Primary Hover: Background #00695C
- Secondary: Background #0288D1, Text #FFFFFF
- Ghost: Border Primary, Text Primary

### Status Badges
- Booked: Success (#43A047)
- Pending: Warning (#FB8C00)
- Failed: Error (#E53935)
- Info: Info (#039BE5)
- Inbound: Primary (#00897B)
- Outbound: Secondary (#0288D1)
